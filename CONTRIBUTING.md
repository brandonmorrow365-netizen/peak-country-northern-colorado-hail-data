# Contributing research corrections

This dataset accepts evidence-backed defect and documentation reports through the public repository's GitHub Issues, not direct unreviewed modification of the authoritative observation files.

To submit a correction after release, identify the specific file and version, relevant public `observation_id` or `event_group_id`, the alleged error, and a verifiable public source record. Explain whether the issue affects source reporting, provenance, identity, event grouping, geographic QA, summary computation, documentation or accessible presentation.

Do not include protected photos, raw restricted datasets, private personal information, customer details, insurance documentation or credentials. Maintainers evaluate the provenance, license rights and methodological implications before making a decision. Any accepted scientific changes are rebuilt through the controlled versioned pipeline, not by editing independent CSV/JSON/GeoJSON/Parquet copies.

See `CORRECTIONS.md` for the currently verified contact method. No contribution implies endorsement by NOAA/NCEI, NWS, SPC, CoCoRaHS or Census.
