# Source provenance and verified historical acquisitions

**Scope:** V1.0.0, 2016–2025. **Status:** published 2026-10-11. The approved seven source/data/QA categories and rights descriptions remain in `sources/source-manifest.json`. See `sources/source-retrieval-details.json` for dated URLs and SHA-256 information from validated acquisition manifests. These are original acquisition records, not newly retrieved or invented sources, and raw source files are not distributed.

**NOAA/NCEI historical backbone:** 10 dated and hash-verified annual Storm Events archives (2016–2025); correction/version dates, retrieval dates, filenames, source URLs, source sizes and source SHA-256 are shown individually. The final historical representation governs matching report lineages, but agency correction releases can subsequently change the history.

**CoCoRaHS:** 24 time-period network API page metadata entries with retrieval checksums and query offsets. The approved processing spatially filtered data to Weld/Larimer using county polygon QA. Network-wide pagination totals must not be counted as county observations; raw responses and media are excluded. CoCoRaHS source-layer CC BY 3.0 and normalization-change notices are independently preserved.

**SPC:** 122 approved dated hail-report CSV source artifacts with source URLs, source-byte checksums and target-row counts. A source retrieval on 2022-02-24 returned HTTP 502 and was not fabricated. SPC is preliminary/derivative, not independent confirmation when matching an NWS report.

**NWS:** preliminary local reports are REFERENCE_ONLY for V1 because complete original decade coverage was not confirmed; no fictional full source archive/checksum is represented.

**MRMS/MESH:** the official `CONUS/MESH_00.50` archive prefix and three verified listing-page hashes are listed without opaque cloud pagination tokens. The project archive begins October 14, 2020; radar context is not ground confirmation.

**Census TIGER/Line:** verified official 2026 Colorado county-boundary package; the original T07 source hash, filename, retrieval date, byte size, projection and County layer are included for Weld/Larimer spatial QA.

**Raw mPING:** NOT_USED and not redistributed. An NCEI event source label mentioning mPING does not make a raw mPING record available.

The Lincoln Park coordinate is a Peak Country-selected **methodological reference**, not a municipal GIS dataset, business address or hail observation. For source rights and limitations see `ATTRIBUTION.md`, `RIGHTS.md`, `METHODOLOGY.md` and `LIMITATIONS.md`.
